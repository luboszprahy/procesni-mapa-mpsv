# admin query

Run tenant-level resource query.

## Arguments

- `--query` (`-q`) - Resource Query JSON as a string.
- `--query-file` (`-qf`) - Path to a JSON file containing the Resource Query.
- `--output-type` (`-ot`) - Output type for query results (Defaults to Grid)
- `--output-file` (`-of`) - Path to save query results. Format depends on --output-type: raw JSON for Json, simple text for List, and CSV for Grid.
