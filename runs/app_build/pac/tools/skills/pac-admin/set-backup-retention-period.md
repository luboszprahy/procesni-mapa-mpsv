# admin set-backup-retention-period

Sets the backup retention period in days as provided. Valid values are: 7, 14, 21, 28.

## Arguments

- `--environment` (`-env`) - Environment URL or ID of the Environment that requires backup.
- `--backup-retention-period` (`-br`) - Sets the backup retention period in days as provided. Valid values are: 7, 14, 21, 28.
- `--async` (`-a`) - Optional boolean argument to run pac verbs asynchronously, defaults to false.
- `--max-async-wait-time` (`-wt`) - Max asynchronous wait time in minutes. The default value is 60 minutes.
