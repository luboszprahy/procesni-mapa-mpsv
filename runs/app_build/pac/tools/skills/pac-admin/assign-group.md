# admin assign-group

Assign group to target Dataverse environment with specified security role.

## Arguments

- `--environment` (`-env`) - ID or URL of the environment to assign a user to.
- `--group` (`-g`) - Microsoft Entra ID object ID of group to assign to target Dataverse environment.
- `--group-name` (`-gn`) - Name of the group or team to create in Dataverse.
- `--role` (`-r`) - Name or ID of security role to be applied to user
- `--team-type` (`-tt`) - Type of team.
- `--membership-type` (`-mt`) - Team membership type.
- `--business-unit` (`-bu`) - ID of business unit to associate application user with.
