# admin set-runtime-state

Update environment administration mode.

## Arguments

- `--environment` (`-env`) - URL or ID of the environment for which administration mode needs to be updated.
- `--runtime-state` (`-rs`) - The environment runtime state
- `--background-operations` (`-bo`) - The environment background operations state
- `--async` (`-a`) - Optional boolean argument to run pac verbs asynchronously, defaults to false.
- `--max-async-wait-time` (`-wt`) - Max asynchronous wait time in minutes. The default value is 60 minutes.
