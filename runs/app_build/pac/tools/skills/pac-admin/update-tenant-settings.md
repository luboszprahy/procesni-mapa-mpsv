# admin update-tenant-settings

Update tenant settings.

## Arguments

- `--settings-file` (`-s`) - The .json file with tenant settings.
- `--setting-name` (`-n`) - Name of the setting to be updated. For example: powerPlatform.helpSupportSettings.useSupportBingSearchByAllUsers
- `--setting-value` (`-v`) - Value of the setting to be updated.
