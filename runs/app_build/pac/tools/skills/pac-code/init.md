# code init

Initializes a Code app in the current directory.

## Arguments

- `--environment` (`-env`) - Specifies the target Dataverse. The value may be a Guid or absolute https URL. When not specified, the active organization selected for the current auth profile will be used.
- `--displayName` (`-n`) - The display name of the Code app.
- `--description` (`-d`) - The description of the Code App.
- `--buildPath` (`-b`) - The directory of your apps build assets.
- `--fileEntryPoint` (`-f`) - The entry point for the app to load from.
- `--appUrl` (`-a`) - The local url the app is running on.
- `--logoPath` (`-l`) - The path to the logo file for the app.
- `--region` (`-c`) - The region to host the Code app in.
