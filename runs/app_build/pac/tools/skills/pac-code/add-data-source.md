# code add-data-source

Adds a new datasource to the app.

## Arguments

- `--apiId` (`-a`) - The api id of the datasource.
- `--connectionId` (`-c`) - The connection id of the datasource.
- `--table` (`-t`) - The table name of the datasource.
- `--dataset` (`-d`) - The dataset name of the datasource.
- `--storedProcedure` (`-sp`) - The stored procedure name to add (only supported for shared_sql).
- `--environment` (`-env`) - The environment URL to connect to the data source.
- `--logLevel` (`-l`) - The logging level for the command.
- `--connectionRef` (`-cr`) - The connection reference ID.
- `--solutionId` (`-s`) - The solution ID of the connection reference. Used only when connection reference parameter is present.
