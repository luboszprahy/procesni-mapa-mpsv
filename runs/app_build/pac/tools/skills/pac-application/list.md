# application list

List available Dataverse applications from Microsoft Marketplace

## Arguments

- `--environment` (`-env`) - List available Dataverse applications for given environment (by ID or url); if not specified, list all applications in the tenant
- `--output` (`-o`) - Location of the JSON file to be created with list of the Dataverse applications from Microsoft Marketplace
- `--installState` (`-s`) - Filter by application install state
