# solution add-solution-component

Add one or more solution components to the target unmanaged solution in Dataverse.

## Arguments

- `--environment` (`-env`) - Environment URL or ID of the target environment.
- `--solutionUniqueName` (`-sn`) - Name of the solution.
- `--component` (`-c`) - The schema name or ID of the component to add to the target solution.
- `--componentType` (`-ct`) - The value that represents the solution component that you're adding.
- `--AddRequiredComponents` (`-arc`) - Indicates whether other solution components required by the solution component that you're adding should also be added to the unmanaged solution.
- `--async` (`-a`) - Imports the solution asynchronously.
