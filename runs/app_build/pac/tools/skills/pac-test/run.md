# test run

(Preview) Execute tests defined in a Test Plan file

## Arguments

- `--test-plan-file` (`-test`) - Path to the Test Plan file
- `--environment-id` (`-env`) - Environment ID for the app to be tested.
- `--tenant` (`-t`) - Tenant ID for the app being tested
- `--output-directory` (`-o`) - Path to save test output and logs
- `--domain` (`-d`) - The player domain for the app being tested for Canvas provider or endpoint for other provider types.
- `--user-auth` (`-u`) - The user authentication type for app being tested
- `--provider` (`-p`) - The application type being tested
- `--auth` (`-a`) - The certificate provider for the user authentication for app being tested
- `--queryparams` (`-q`) - Query parameters for the app being tested
- `--use-static-context` (`-c`) - Enable use of static context for Playwright browser
- `--log-level` (`-l`) - Log detail level
