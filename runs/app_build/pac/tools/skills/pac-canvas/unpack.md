# canvas unpack

(Preview) Extract an msapp file into sources

## Arguments

- `--msapp` - Path to .msapp file
- `--sources` - Directory to sources to be unpacked
- `--layout` - The layout to use for the sources directory. Note: 'Experimental' layout is deprecated and will be removed in a future release. Use 'SourceCode' layout for the latest supported layout.
- `--overwrite` - Allow file overwrite
