# canvas download

Download canvas app as .msapp file

## Arguments

- `--environment` (`-env`) - Specifies the target Dataverse. The value may be a Guid or absolute https URL. When not specified, the active organization selected for the current auth profile will be used.
- `--name` (`-n`) - Canvas app exact, partial name, or App ID
- `--file-name` (`-f`) - File name (usually with .msapp extension). If not provided file is saved in current directory with 'appname'.msapp
- `--extract-to-directory` (`-d`) - Directory name to extract canvas app to
- `--overwrite` (`-o`) - Allow file overwrite
