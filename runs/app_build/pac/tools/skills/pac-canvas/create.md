# canvas create

Generate a canvas app from a custom connector

## Arguments

- `--msapp` - Path to .msapp file to be generated
- `--connector-id` - The ID of the Connector to generate the Power App from.
- `--connector-display-name` - The display name of the Connector to generate the Power App from.
- `--environment` - The target Environment ID or URL. The default value is the environment of your currently active Dataverse Auth Profile.
