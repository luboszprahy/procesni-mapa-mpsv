# pages clone

Create Power Pages website content based on existing website content.

## Arguments

- `--path` (`-p`) - Path of website content.
- `--outputDirectory` (`-od`) - Path where the Power Pages website content is saved after cloning.
- `--overwrite` (`-o`) - Overwrites the existing folder present at the output path.
- `--name` (`-n`) - Name for the cloned Power Pages site. If not provided, defaults to 'Copy of <original-site-name>'.
