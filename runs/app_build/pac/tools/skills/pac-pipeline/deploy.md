# pipeline deploy

Start pipeline deployment.

## Arguments

- `--environment` (`-env`) - Deployment Environment
- `--solutionName` (`-sn`) - Solution Name
- `--stageId` (`-sid`) - Deployment Stage ID
- `--currentVersion` (`-cv`) - Current solution version
- `--newVersion` (`-nv`) - New solution version
- `--wait` (`-w`) - Wait until the deployment finishes.
