# plugin init

Initializes a directory with a new Dataverse plug-in class library.

## Arguments

- `--signing-key-file-path` (`-sk`) - Relative path to the Dataverse plug-in assembly originator key file for signing.
- `--outputDirectory` (`-o`) - Output directory
- `--author` (`-a`) - One or more authors of the Dataverse Plug-in Package.
- `--skip-signing` (`-ss`) - Skip plug-in assembly signing that gives the plug-in assembly a strong name. The default value is 'false'.
