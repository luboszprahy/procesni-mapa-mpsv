# model create

Creates a new model-driven app.

## Arguments

- `--environment` (`-env`) - Specifies the target Dataverse. The value may be a Guid or absolute https URL. When not specified, the active organization selected for the current auth profile will be used.
- `--name` (`-n`) - The display name for the new model-driven app.
- `--description` (`-d`) - Description for the new model-driven app.
- `--solution` - Solution unique name to add the app to. Defaults to 'Default' if not specified.
- `--publish` - Publish the app after creation.
