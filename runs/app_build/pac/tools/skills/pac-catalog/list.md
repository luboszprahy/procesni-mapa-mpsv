# catalog list

List all published catalog items from the current Dataverse organization.

## Arguments

- `--environment` (`-env`) - Url or ID of the environment that has catalog installed. When not specified, the active organization selected for the current auth profile will be used.
- `--catalog-item-name` (`-n`) - Catalog item name to search for.
- `--catalog-item-id` (`-cid`) - Catalog item ID to search for. When catalog item ID is used, catalog item name is ignored.
- `--include-active` (`-ia`) - Include active items.
