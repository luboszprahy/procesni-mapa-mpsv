# copilot quarantine

Quarantine status of copilot agent.

## Arguments

- `--environment` (`-env`) - Environment (ID, org ID, url, unique name, or partial name).
- `--bot-id` (`-id`) - The ID of the copilot to quarantine/unquarantine.
- `--status` (`-s`) - Quarantine status value. true = quarantine, false = unquarantine. Defaults to true.
