# copilot pack

Package a Copilot Studio agent workspace into a solution zip file.

## Arguments

- `--publisher-prefix` (`-pp`) - Publisher customization prefix for the solution.
- `--project-dir` (`-pd`) - Agent workspace directory to package. Defaults to current directory.
- `--solution-name` (`-sn`) - Solution unique name. If omitted, derived from the agent schema name.
- `--output-path` (`-op`) - Output path for the solution zip file. Defaults to current directory.
