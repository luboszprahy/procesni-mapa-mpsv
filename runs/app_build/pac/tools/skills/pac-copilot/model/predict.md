# copilot model predict

Sends text or prompt to AI Model

## Arguments

- `--environment` (`-env`) - Specifies the target Dataverse. The value may be a Guid or absolute https URL. When not specified, the active organization selected for the current auth profile will be used.
- `--model-id` (`-id`) - AI Builder model Id
- `--model-name` (`-n`) - Full or partial AI Model name
- `--prompt` (`-p`) - Prompt to send to AI Model
- `--text` (`-t`) - Text to send to AI Model
